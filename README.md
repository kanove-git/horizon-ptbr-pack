# Horizon em português do Brasil

Pacote de recursos que traduz para o português do Brasil os textos do próprio [Horizon](https://github.com/horizon-rust/horizon) (Minecraft Java Edition 26.3 reescrito em Rust): **Ajustes do Horizon**, gráficos, controle, extras, mods, shaders, agente de IA, multijogador e mensagens — 390 textos, com a terminologia oficial do Minecraft em português.

O Minecraft já traduz os próprios menus; este pacote cobre o que é do Horizon e aparecia em inglês.

## Instalar

1. Baixe este repositório como `.zip` (ou a versão em Releases) e coloque em `resourcepacks/` na pasta do jogo do Horizon (`%APPDATA%\horizon\resourcepacks`).
2. No jogo: **Opções → Pacotes de recursos**, ative **Horizon PT-BR**.
3. Idioma do jogo em **Português (Brasil)**.

Funciona sem compilar nada e continua valendo nas atualizações (as chaves de tradução do Horizon são estáveis). Textos novos de versões futuras aparecem em inglês até serem adicionados aqui.

## O que não dá para traduzir por pacote

Alguns textos estão fixos no código do jogo e não passam pelo sistema de idiomas — veja [HARDCODED.md](HARDCODED.md). Esses precisam de uma mudança no próprio Horizon.
